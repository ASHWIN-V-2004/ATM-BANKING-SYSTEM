# Exp-1 ATM & BANKING SYSTEM

# AIM:

To develop an ATM and Banking System that allows users to perform basic banking operations such as checking balance, depositing money, withdrawing money, and viewing account details securely.

# SRS (Procedure):

rocedure:
1. Start the program.
2. Display the ATM and Banking System menu.
3. Ask the user to enter their PIN for authentication.
4. Display the available banking operations.
5. Allow the user to select an option:
   - Balance Enquiry
   - Cash Deposit
   - Cash Withdrawal
   - Account Details
   - Exit
6. Perform the selected operation.
7. Update the account balance after deposit or withdrawal.
8. Display the transaction details and updated balance.
9. Repeat the process until the user selects Exit.
10. Stop the program.
